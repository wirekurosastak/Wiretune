# Wiretune player

The Flutter player for Linux, Windows, macOS, Android (phones, tablets, Android TV, Android Auto), iOS and Tizen TVs.

```bash
flutter pub get
flutter run -d linux        # or windows, macos, or a device from `flutter devices`
flutter test
```

Building for each platform, signing, and what has been verified: [../docs/development.md](../docs/development.md).
How the code is organised: [../docs/architecture.md](../docs/architecture.md).
