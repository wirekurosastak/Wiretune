# Wiretune player

The Flutter player for Linux, Windows, macOS, Android (phones, tablets, TV, Auto), iOS and Samsung's Tizen TVs.

```bash
flutter run -d linux        # or windows, macos, or a device from `flutter devices`
flutter test
```

Building for each platform and signing: [docs/building.md](../docs/building.md). Testing, debugging and what has been
tried where: [docs/development.md](../docs/development.md). How the code is organised:
[docs/architecture.md](../docs/architecture.md).
