# Wiretune server

Indexes one music folder and serves it to the Wiretune players over HTTP, with accounts and per-account favorites,
play counts and playlists.

Building it: [docs/building.md](../docs/building.md#server). Options, accounts and running it as a service:
[docs/server.md](../docs/server.md). The HTTP API: [docs/api.md](../docs/api.md).
